TITLE:
FastContentChunk: JMH Benchmark - 840 MB/s Native SIMD Text Chunker ⚡

DESCRIPTION:
Official OpenJDK JMH (Java Microbenchmark Harness) performance benchmark for FastContentChunk. Measuring native C++ SSE2 SIMD tokenization throughput across Token, Sentence, Paragraph, and Recursive Hybrid strategies.

BENCHMARK RESULTS (JMH):
- Fixed Token Window: 840 MB/s throughput
- Paragraph Boundary Mode: 520 MB/s throughput
- Recursive Hybrid Strategy: 480 MB/s throughput
- Recall Precision: 96.8% boundary retention

RUN BENCHMARK LOCALLY:
Execute `run-benchmark.bat` in the repository root.
